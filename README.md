# Prediction_of_Production_Sales

## This project will be a sales prediction for food items sold at various stores 

Qusta Bahu

### The goal of this is to help the retailer understand the properties of products and outlets that play crucial roles in increasing sales.
Often times when stores want to work and earn the highest sales possible while doing so. There are so many properties to choose from and knowing which feture will be the best feture to include can be challenging.
The aim is to build a predictive model and predict the sales of each product at a particular outlet.

## Data Source:
DS Prediction of Production
https://datahack-prod.s3.amazonaws.com/train_file/train_v9rqX0R.csv

For this dataset, there were 8523 rows and 12 columns.
